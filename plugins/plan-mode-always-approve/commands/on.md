# On

Create an empty file at `.claude/plan-mode-always-approve` in the project root. While it is there,
plan approval in this project is answered for the user and the session continues in auto mode.

Check that the file is ignored by git, and say so if it is not — committing it switches this on for
everyone on the team who has the plugin installed.

Touch nothing else. Report in one line.
